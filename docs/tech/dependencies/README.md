# Dependencias

No hay manifiestos (`package.json`, lockfiles) ni dependencias de código: el sitio no usa librerías JS ni CSS de terceros.

Dependencias externas en tiempo de ejecución:

| Dependencia | Propósito en este proyecto | Versión | Uso | Límites |
|---|---|---|---|---|
| Google Fonts (CSS2 API) | Tipografías Exo 2 (títulos), Poppins (cuerpo), Inter (botones) | Sin versión (servicio) | `<link>` en `index.html`, `5-elementos.html`, `estrategia.html`, `alcance.html`, `estructura.html`, `estructura-tarea-1.html`, `estructura-tarea-2.html`, `esqueleto.html`, `superficie.html` y `superficie-usuario-1.html`, `-2` y `-3`, `superficie-guion.html` y sus copias en `en/` | Sin conexión, el navegador usa la fuente `sans-serif` de respaldo |

Herramientas de diseño mencionadas en el contenido (Figma, Make, Photoshop, UX Tweak): no son dependencias del código.

No hay bibliotecas propias del cliente declaradas (pregunta abierta en `.cardenal/repository-context.json`).
