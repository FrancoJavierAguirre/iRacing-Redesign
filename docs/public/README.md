# Documentación del producto

**iRacing — Rediseño UX/UI** es un case study de portfolio (Franco Aguirre, 2025) que cuenta cómo se rediseñó, de forma no oficial, la plataforma de iRacing donde los pilotos buscan carreras, se registran y compran contenido. Es un sitio estático en español, pensado para que reclutadores y equipos de diseño lo lean.

- [Funcionalidades](funcionalidades.md): páginas, secciones, flujos de navegación y estado (implementado / parcial / pendiente).
